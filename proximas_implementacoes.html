Fase 1: MVP do Chatbot de Inteligência Artificial

1.1 Integração com Endpoint Oficial Gemini 2.5 Flash

Alta Prioridade

Configurar rotas serverless na Vercel para intermediação segura com a API do Google AI Studio, ocultando a API Key no servidor backend.

  • Criação de rota segura /api/chat/reply.
  • Substituição da chamada direta do cliente para o endpoint seguro local.
  • Proteção do tráfego usando criptografia HTTPS padrão.

1.2 Mecanismo de Fallback Inteligente Sem Chave

Média Prioridade

Garantir que a aplicação forneça suporte de análise mesmo se o usuário final não possuir chave própria da API do Gemini cadastrada.

  • Refinamento do validador baseado em expressões regulares em src/utils/chatbot.ts.
  • Respostas estáticas enriquecidas para perguntas sobre os relatórios de erros estruturais do balancete.
  • Aviso sutil na interface instruindo o usuário a adquirir a chave caso necessite de interpretações avançadas.

1.3 Ajustes de UX e Responsividade do Chatbot

Baixa Prioridade

Ajustar os estados de visualização e animações do painel lateral (Drawer) do chatbot.

  • Responsividade para telas de tablets e dispositivos móveis (largura menor que 768px).
  • Suavização na transição de entrada/saída usando CSS Vanilla transform.
  • Opção rápida de limpar histórico da conversa para liberar memória da sessão.

Fase 2: IA Contextual e Histórico Persistente

2.1 Modelagem de Sessões de Chat (Turso DB)

Alta Prioridade

Modelar e migrar tabelas relacionais de histórico de chats para permitir que o usuário retome conversas anteriores.

  • Criação das tabelas chat_sessions e chat_messages no banco de dados SQLite distribuído da Turso.
  • Relacionamento das chaves estrangeiras com a tabela de usuários autenticados (users).
  • Políticas de expiração automática ou limpeza sob demanda do usuário.

2.2 Otimização e Controle de Tokens no Prompt

Média Prioridade

Garantir que balancetes muito extensos não estourem os limites de tokens da API do Gemini, mantendo o custo operacional sob controle.

  • Implementação de algoritmo de sumarização pré-prompt em src/utils/gemini.ts.
  • Compactação de listas de saldos muito grandes, retendo apenas as contas com alertas ativos e totalizadores.
  • Cálculo e contagem aproximada de tokens no frontend antes do disparo.

Fase 3: Inteligência Contábil Avançada

3.1 Módulo de Comparação Temporal de Balancetes

Alta Prioridade

Permitir que a IA compare múltiplos PDFs carregados em períodos subsequentes (ex: Janeiro e Fevereiro) e aponte anomalias na evolução das contas.

  • Mecanismo de ordenação cronológica das CompanyReport processadas.
  • Detecção automática de contas que surgiram ou desapareceram entre os meses.
  • Geração de alertas para flutuações anormais de saldo (ex: aumentos repentinos no grupo de despesas).

3.2 Parecer Contábil Sintético Automatizado (PDF)

Média Prioridade

Habilitar exportação de um relatório em PDF que inclua uma seção de parecer gerada pela IA, pronto para envio ao cliente final da contabilidade.

  • Integração da resposta estruturada da IA na exportação via jspdf.
  • Formatação profissional do parecer com espaços para assinatura técnica.
  • Possibilidade de edição manual do texto gerado pela IA antes da exportação definitiva.

Melhorias de Infraestrutura, Qualidade e Segurança

Q.1 Criptografia Simétrica de Chaves Externas no Banco

Alta Prioridade

Caso o usuário escolha salvar a chave do Gemini na sua conta em nuvem (em vez do localStorage), os dados devem ser criptografados com algoritmo simétrico AES-256 no Turso.

  • Utilização do módulo nativo crypto do Node.js no backend.
  • Chave de criptografia mestre rotacionável baseada em variáveis de ambiente na Vercel.

Q.2 Testes Automatizados no Parser Athenas3000

Média Prioridade

Implementação de testes de regressão automatizados para certificar a leitura correta das 7 colunas obrigatórias do sistema Athenas3000.

  • Criação de mock de dados simulando PDFs válidos e inválidos.
  • Testes unitários cobrindo o mapeamento de: Conta Contábil, Cod. R., Nome da Conta, Saldo Anterior, Débito, Crédito e Saldo Atual.
